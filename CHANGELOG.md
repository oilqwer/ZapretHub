# История изменений

## 2.0.2

Первый публичный релиз ветки 2.0: полная переработка на C# / .NET 8 с интерфейсом на WebView2 (ветка 1.x была на Python).

- Один самодостаточный `ZapretHub.exe`, без установки Python.
- Движок zapret обновляется напрямую с GitHub Flowseal; SHA-256 берётся из `digest` ответа GitHub API, отказ при отсутствии или несовпадении.
- Безопасная распаковка, перенос пользовательских списков и настроек, резервная копия `engine.backup`, откат при ошибке; останавливается только winws, которым управляет приложение.
- Встроенный Telegram-прокси на C# (передача файлов более 50 МБ), AI DNS, диагностика, автоподбор стратегии.
- Подписанный манифест Ed25519 — для собственных компонентов проекта.
- Повторная установка той же версии не вытесняет `engine.backup` с предыдущей версией.
- Кнопка «Обновить hosts» временно отключена: подписанный список записей ещё не опубликован.
- Диалог исключения Защитника: кнопки не выходят за границы окна при любом масштабе; удаление исключения требует подтверждения с точным путём.
- Фирменный значок в окне, панели задач и трее; постоянный AppUserModelID.
