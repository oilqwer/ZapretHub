# Локальная тестовая сборка AI DNS

Сборка подготовлена 5 ноября 2026 года. Изменения не опубликованы в GitHub и не являются релизом.

## Что изменено

- AI DNS больше не устанавливает свои серверы на сетевые адаптеры. Локальный посредник обслуживает только ИИ-домены через правило NRPT Windows.
- DNS корпоративного домена, 1С, сетевых принтеров, обычных сайтов и VPN остаётся прежним. Перечень ИИ-доменов находится в `AiDnsPolicy.Domains`; весь `google.com` в него не входит.
- Добавлен DNS-AI: `194.87.196.13`, `45.151.102.219`, DoH `https://dns.dns-ai.ru/dns-query`. Незашифрованный DNS для этих адресов запрещён.
- Перед включением проверяются DNS и HTTPS для ChatGPT и Gemini. При недоступности выбранных серверов используются резервные DNS-AI, WebShift и GeoHide, если включён автоматический выбор.
- ChatGPT и Gemini могут использовать разные серверы. При отказе DNS, некорректном ответе, отказе HTTPS или обнаруженном сообщении о неподдерживаемом регионе посредник пробует следующий сервер. Недоступный сервер исключается на 30 секунд; проверка HTTPS кэшируется на две минуты.
- Если перед включением доступного маршрута для одного из этих сервисов нет, правило Windows не устанавливается. Приложение сообщает об ошибке.
- При выключении и завершении приложения удаляется только принадлежащее ему правило. При аварийном завершении очистку выполняет отдельный процесс; при следующем запуске также проверяются оставшиеся правила завершённых процессов.
- Существующие пересекающиеся политики DNS не заменяются: приложение сообщает о конфликте. DNS и DoH других программ не изменяются.

## Как проверить

1. Закройте прежнюю версию Zapret Hub.
2. Запустите `ZapretHub-AiDnsTest.exe` из папки `test-ready`, подтвердив стандартное повышение прав Windows.
3. На странице AI DNS нажмите «DNS-AI», оставьте включённым автоматический выбор резервного DNS, сохраните настройки и включите переключатель.
4. Посмотрите, какие серверы выбраны для ChatGPT и Gemini. Откройте оба сервиса, затем проверьте доступ к 1С и обычную печать на своём принтере.
5. Выключите AI DNS и полностью завершите приложение через меню трея. Настройки DNS адаптеров должны остаться такими же, как до теста.

Закрытие окна может скрывать приложение в трей согласно существующей настройке. Пока приложение работает в трее, AI DNS продолжает работать.

## Ограничения проверки

Проверка HTTPS выполняется без авторизации. Она обнаруживает явные региональные отказы, но не проверяет право конкретного аккаунта использовать сервис. Собственный DoH браузера, отдельный прокси браузера и DNS-перехват VPN могут обходить системное правило; приложение не изменяет настройки этих программ.

Во время подготовки оба адреса DNS-AI завершали запросы по тайм-ауту из текущей сети. WebShift и GeoHide прошли проверку DNS/HTTPS. При автоматическом выборе механизм выбрал `31.31.207.68` для обоих сервисов. Это результат сетевой проверки, не проверки авторизованного аккаунта.

## Выполненные проверки

- Автоматические проверки протокола, границ доменов, переключения серверов, отдельных маршрутов Gemini/ChatGPT, UDP/TCP, IPv6 и отката жизненного цикла. Отчёт: `.test-results/aidns.txt`.
- Проверки сценариев Windows с подменёнными системными командами: чужие корпоративные/VPN-политики сохраняются, конфликтующие правила не перезаписываются, собственные правила удаляются при откате. Скрипт: `tests/aidns_policy_mock.ps1`.
- Реальный системный тест с повышением Windows: запрос случайного имени `.invalid` прошёл через NRPT и локальный посредник. После очистки снимки DNS всех адаптеров и исходных правил совпали. Отчёт: `.test-results/windows-admin.txt`.
- Проверка помощника из упакованного EXE: он оставался активным при работающем родительском процессе, дождался аварийного завершения тестового процесса и завершил очистку. Существующие политики не изменились. Отчёт: `.test-results/watchdog-admin.txt`.
- Итоговый EXE прошёл 32 автоматические проверки и визуальную самопроверку страниц интерфейса; ошибок JavaScript не обнаружено.
- Сетевая проверка провайдеров и автоматического выбора: `.test-results/provider-probe.json`, `.test-results/failover-live.json`.

Фактический вход в 1С, отправка задания на принтер и авторизованный вход в ИИ-сервисы этими автоматическими тестами не выполняются.
