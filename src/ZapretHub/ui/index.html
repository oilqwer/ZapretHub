Game Filter

Расширяет обход на порты выше 1023 — для игр и программ на нестандартных портах. Без необходимости держите выключенным.

Например: 1024-1934,1936-65535

Fake-пакеты

Какие «подставные» пакеты отправлять для UDP Discord и Game Filter. Меняйте, если не подключаются голосовые каналы или игры.

Zapret Hub проверяет релизы напрямую на GitHub Flowseal, скачивает официальный архив и сверяет его SHA-256 с данными GitHub (подпись разработчика Flowseal не проверяется). Ваши списки и настройки переносятся, прежний движок сохраняется как резервная копия.

Исключение Защитника Windows

Защитник перестанет проверять папку (winws.exe и драйвер WinDivert). Это нужно только если антивирус удаляет эти файлы. Любой вредоносный файл, попавший в эту папку, тоже не будет проверен. По умолчанию Zapret Hub ничего не добавляет — исключение создаётся только после вашего нажатия на «Добавить».
